# NVIDIA Jetson Series Product Documentation [<img src="https://img.shields.io/badge/NVIDIA_Jetson-Module-76B900?style=flat&logo=nvidia&logoColor=white" alt="NVIDIA Jetson">](https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/)

The NVIDIA Jetson Series comprises high-performance edge AI computing systems built upon NVIDIA's Jetson platform. These robust industrial-grade computers deliver exceptional AI inference performance for demanding computer vision, robotics, and edge computing applications.

## Product Models

| Product Model | NVIDIA Jetson Module | CPU |
|---|---|---|
| `/BPC_EA_100` | Jetson Nano | 4x ARM A57 MPCore |
| `/BPC_EA_200` | Jetson TX2 NX | 2x Denver2 Core + 4x ARM A57 MPCore |
| `/BPC_EA_310` | Jetson Xavier NX | 6x Carmel ARM v8.2 |
| `/BPC_EA_400` | Jetson AGX Xavier | 8x Carmel ARM v8.2 |
| `/BPC_EA_500` | Jetson Orin NX | 6/8-core ARM Cortex-A78AE 64-bit CPU 1.5MB L2 + 4MB L3 |
| `/BPC_EA_500E` | Jetson Orin Nano | 6/8-core ARM Cortex-A78AE 64-bit CPU 1.5MB L2 + 4MB L3 |
| `/BPC_EA_600` | Jetson AGX Orin | 8-core ARM Cortex A78AE 64-bit CPU 2MB L2 + 4MB L3 |
