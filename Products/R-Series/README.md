# R-Series Product Documentation [<img src="https://img.shields.io/badge/RockChip-SoC-blue" alt="RockChip Badge">](https://www.rock-chips.com/a/en/index.html)

The **R-Series** is a family of embedded computing products built around the high-performance **RockChip SoC (System-on-Chip)** platform. This series delivers excellent multimedia processing capabilities and power efficiency for cost-sensitive commertial applications.

## Product Categories

| Category | Form Factor | Description | Target Applications |
|:---|:---|:---|:---|
| **`/BoxPC`** | **Box PC** | Compact, all-in-one commertial computers with rich I/O interfaces and robust construction. | Digital signage, edge computing, retail systems |
| **`/SBC`** | **Single Board Computer** | Full-featured computer on a single board with RockChip processor, memory, and comprehensive connectivity. | Embedded development, IoT gateways, media centers, educational platforms |
