# N-Series Product Documentation [<img src="https://img.shields.io/badge/NXP-SoC-green" alt="NXP Badge">](https://www.nxp.com/ ) 

The **N-Series** is a family of embedded computing products and solutions designed around the powerful and efficient **NXP SoC (System-on-Chip)** platform. This series is targeted at applications requiring robust performance, rich I/O interfaces, and industrial-grade reliability.

## Product Categories

| Category | Form Factor | Description | Target Applications |
|:---|:---|:---|:---|
| **`/BoxPC`** | **Box PC** | All-in-one, ready-to-use industrial computers with computing core, power, and I/O interfaces. | Machine vision, industrial automation, edge gateways |
| **`/Panel`** | **Panel PC** | Integrated touch display and computing unit for human-machine interface. | Interactive kiosks, industrial HMI, retail POS, control panels |
| **`/SBC`** | **Single Board Computer** | Complete computer on a single circuit board with CPU, memory, storage, and standard peripherals. | Prototyping, education, research, medium-volume embedded projects |
| **`/SOM`** | **System on Module** | Minimalist board with core computing unit; connects to carrier board for maximum design flexibility. | High-volume products, space-constrained applications, custom solutions |
