## Download flexbuild source code:

```shell
git clone https://github.com/NXP/flexbuild.git
```

Compilation is executed inside docker:

```shell
$ cd flexbuild
$ . setup.env  (in host environment)
$ bld docker   (create or attach to docker)
$ . setup.env  (in docker environment)
$ bld host-dep (install host dependent packages)

Usage: bld -m <machine>
   or  bld <target> [ <option> ]
```

```shell
bld clean-linux Clean Linux build outputs
bld linux -m imx91evk  Build Linux ---》The generated firmware is in build_lsdk2506/linux/linux/arm64/IMX/
```


Use uuu for flashing (uboot compiled by flexbuild cannot be used in uuu, can use the one compiled in yocto instead):

```shell
How to burn i.MX Debian Linux SDK images generated by Flexbuild to SD card or eMMC device by UUU tool?
Build Debian images by Flexbuild.
$ bld -m imx8mpevk
Generate the sdcard.wic image by flex-installer as follows:
$ flex-installer -i mkwic -m imx8mpevk \
      -f build_<version>/images/firmware_imx8mpevk_sdboot.img \
      -b build_<version>/images/boot_IMX_arm64_<lts_version>.tar.zst \
      -r build_<version>/rfs/rootfs_<lsdk_version>_debian_desktop_arm64
Set the DIP switch to USB serial download mode and burn images by UUU.
$ uuu -b emmc_all build_lsdk2412/bsp/imx-mkimage/imx8mpevk/flash.bin sdcard.wic    (uncompressed format, or '-b sd_all' for SD)
or 
$ uuu -b emmc_all build_lsdk2412/bsp/imx-mkimage/imx8mpevk/flash.bin sdcard.wic.zstd (compressed format, or '-b sd_all' for SD)
```

You can also use balenaEtcher to burn the prepared .wic to an SD card

Use flex-installer to install directly to SD card:

```shell
flex-installer -i pf -d /dev/sdx
flex-installer -d /dev/sdb -m imx91evk -f firmware_imx91evk_sdboot.img -b boot_IMX_arm64_lts_6.6.52 -r rootfs_lsdk2506_debian_desktop_arm64.tar.zst

flex-installer -r rootfs_lsdk_debian_xx_arm64.tar.zst -d /dev/sdx         (only install rootfs partition image)
flex-installer -b boot_IMX_arm64_lts_xx.tar.zst -d /dev/sdx -m <machine>  (only install boot partition image)
flex-installer -f firmware_<machine>_sdboot.img -d /dev/sdx -m <machine>  (only install composite firmware image)

```

## 6. Install package into system

If the root filesystem has already been built, execute this:

```shell
$ sudo chroot build_lsdk2506/rfs/rootfs_lsdk2506_debian_desktop_arm64 apt install <package>
$ sudo chroot build_lsdk2506/rfs/rootfs_lsdk2506_debian_desktop_arm64 apt remove <package>
```

If not yet built, execute this operation

Or add your required packages in `configs/debian/debian_desktop_arm64.yaml`

```shell
$ sudo rm -rf components_lsdk2506/bookworm_desktop_arm64
$ bld clean-rfs  
(clean Debian desktop RootFS)
$ bld rfs        
(build Debian desktop RootFS with the newly added deb package)
```

## Possible issues:

### 1. Cannot fetch code from network:

```shell
Modify this proxy setting
sudo mkdir -p /etc/systemd/system/docker.service.d
sudo vim /etc/systemd/system/docker.service.d/http-proxy.conf
[Service]
Environment="HTTP_PROXY=http://192.168.2.35:7892"
Environment="HTTPS_PROXY=http://192.168.2.35:7892"
Environment="NO_PROXY=localhost,127.0.0.1"

sudo systemctl daemon-reload
sudo systemctl restart docker
```

### 2. Compiled root filesystem does not contain kernel module

```shell
Need to copy manually to the board, or add in build script to copy during compilation, e.g. flex-builder:
    # Add cp modules to rfs by jiamin
    fbprint_n "-------------------------------------"
    fbprint_n "bld-Add cp modules to rfs by jiamin"
    curbrch=`cd $KERNEL_PATH && git branch | grep ^* | cut -d' ' -f2`
	rm -rf $FBOUTDIR/rfs/rootfs_${DISTRIB_VERSION}_${DISTROTYPE}_${DISTROVARIANT}_${DESTARCH}/lib/modules
    #   rm  $FBOUTDIR/rfs/rootfs_${DISTRIB_VERSION}_${DISTROTYPE}_${DISTROVARIANT}_${DESTARCH}/lib/modules
    cp -rf $KERNEL_OUTPUT_PATH/$curbrch/tmp/lib/modules/  $FBOUTDIR/rfs/rootfs_${DISTRIB_VERSION}_${DISTROTYPE}_${DISTROVARIANT}_${DESTARCH}/lib/
    fbprint_n "-------------------------------------"

Root cause is /boot not mounted on mmcblxp1
```

### 3. Partition mount issue

You may find TF card boot uses root filesystem from emmc

```shell
Modify config/imx91xx.conf file uboot environment, then generate boot.src, see above for how to generate .src file
distroboot=\
'env exists fdtfile || setenv fdtfile imx91-11x11-evk.dtb;'\
'env exists image || setenv image Image;'\
'env exists devpart_boot || setenv devpart_boot 1;'\
'setenv devtype mmc;'\
'setenv devnum 1;'\
'if test "${mmcdev}" = "1"; then'\
' setenv rootdev mmcblk1p3;'\
' else'\
' setenv rootdev mmcblk0p3;'\
' fi;'\
'setenv bootargs console=ttyLP0,115200 earlycon root=/dev/${rootdev} rw rootwait ${othbootargs};'\
'ext4load mmc ${mmcdev}:${devpart_boot} ${fdt_addr} ${fdtfile};'\
'ext4load mmc ${mmcdev}:${devpart_boot} ${loadaddr} ${image};'\
'booti ${loadaddr} - ${fdt_addr}'

```

You can use the following command to view the current mounted root filesystem (default is root=PARTUUID=\$partuuidr):

```shell
root@debix-somc:~# cat /proc/cmdline 
console=ttyLP0,115200 earlycon root=/dev/mmcblk1p3 rw rootwait

```

### 5. Network automatic IP acquisition

```shell
Enable built-in systemd-networkd service:
systemctl enable systemd-networkd
systemctl restart systemd-networkd
Add etc\systemd\network\10-end0.network file for interface requiring auto control:
[Match]
Name=end0

[Network]
DHCP=yes


```

Using NetworkManager.service may cause wifi frequent disconnections

```
If you want to use NetworkManager.service, use nmcli instead of wpa_supplicant:
nmcli dev wifi list
nmcli dev wifi connect "YourWiFiName" password "YourPassword"
nmcli dev wifi connect BH123 password 1234567890
nmcli connection show


Connected wifi passwords are saved in:
cat /etc/NetworkManager/system-connections/BH123.nmconnection
```

Check which network management service is running

```

systemctl list-units --type=service | grep -Ei 'network|netplan'
```

If not using automatic network management, you need to configure manually:

```shell
ifconfig end0 up
ifconfig end1 up
dhclient
ip route del default
ip route add default via 192.168.2.254 dev end0 metric 101
ip route add default via 192.168.2.254 dev end1 metric 102

route -n
```

If DNS resolution fails:

```
echo "nameserver 8.8.8.8" > /etc/resolv.conf
```

### 9. Auto-mount mmcblkxp1

The compiled image, device tree, modules, boot.src, firmware are in `/dev/mmcblk1p1`

If you want to auto mount, add to /etc/fstab

```shell
root@debix-somc:/boot# cat /etc/fstab 
# UNCONFIGURED FSTAB FOR BASE SYSTEM
/dev/mmcblk1p1    /boot                  auto      defaults               1  1

```

### 10. Update uboot image on Linux side

The public uboot build cannot be directly flashed to emmc by uuu, so it can be updated later

```shell
echo 0 > /sys/block/mmcblk0boot0/force_ro
echo 0 > /sys/block/mmcblk0boot1/force_ro
dd if=/usr/local/polyhex/firmware_imx91evk_sdboot.img of=/dev/mmcblk0boot0
dd if=/usr/local/polyhex/firmware_imx91evk_sdboot.img of=/dev/mmcblk0boot1
dd if=/usr/local/polyhex/firmware_imx91evk_sdboot.img of=/dev/mmcblk0 bs=1k seek=32 conv=fsync
echo 1 > /sys/block/mmcblk0boot0/force_ro
echo 1 > /sys/block/mmcblk0boot1/force_ro
sync
```
